# Other libraries

Use what the project already uses.

- **FastAPI / pydantic:** v2 idioms (check installed major). Separate request, response, and persistence models; declare `response_model`. `async def` only when the whole path is non-blocking. One DB session per request via a `yield` dependency.
- **SQLAlchemy / Alembic:** 2.0 style (`select()`, `Mapped[...]`). Explicit transaction boundaries; choose `selectinload` / `joinedload` deliberately. Review autogenerated migrations; same zero-downtime rules as Django.
- **Celery:** idempotent tasks that take IDs, with explicit `autoretry_for`, backoff, `max_retries`, and time limits. Enqueue via `transaction.on_commit`.
- **HTTP clients:** always set timeouts; retry only idempotent calls; raise on bad status.
- **Typing:** `django-stubs` / `djangorestframework-stubs` for Django projects.
